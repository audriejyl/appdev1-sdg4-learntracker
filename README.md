# LearnTracker (SDG 4 – Quality Education)

## Project Description
LearnTracker is a single-page web application built using Angular. It helps users explore and track educational resources such as books using the Open Library API.

This project supports Sustainable Development Goal 4: Quality Education, which focuses on ensuring inclusive and equitable quality education and promoting lifelong learning opportunities.

---

## SDG Chosen
**SDG 4 – Quality Education**

---

## Rationale
We chose SDG 4 because education is essential for personal and community development. This application aims to make learning resources more accessible through a simple and interactive web platform.
