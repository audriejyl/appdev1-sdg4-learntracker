# LearnTracker (SDG 4 – Quality Education)

## Project Description
LearnTracker is a single-page web application built using Angular. It helps users explore and track educational resources such as books using the Open Library API.

This project supports Sustainable Development Goal 4: Quality Education, which focuses on ensuring inclusive and equitable quality education and promoting lifelong learning opportunities.

---

## SDG Chosen
**SDG 4 – Quality Education**

---

## Rationale
We chose SDG 4 because education is essential for personal and community development. This application aims to make learning resources more accessible through a simple and interactive web platform.

## ⚙️ Project Setup

### Clone the Repository
```bash
git clone https://github.com/yourusername/appdev1-sdg4-learntracker.git
cd appdev1-sdg4-learntracker/appdev1-sdg4-learntracker-main
```

### Install Dependencies
```bash
npm install
```

### Running the Application

Start the Angular development server:

```bash
npm start
```

The application will be available at `http://localhost:4200/`

## 🧪 Testing
```bash
npm test
```

## 🚀 Features

- **Angular Signals**: Reactive state management using Angular's new Signals API
- **Functional Guards**: Modern functional auth and deactivate guards with `inject()`
- **Open Library API Integration**: Real-time book data fetching instead of hardcoded data
- **Async Pipe**: Observable handling in templates
- **@Input/@Output**: Parent-child component communication
- **Semantic HTML**: Proper semantic markup for better accessibility
- **Built-in Pipes**: Uses date and titlecase pipes in templates
- **Error Handling**: Graceful fallback to local data on API failure
